# Huang seedfunding proposal

Narrated, animated overview of the Huang Complex Supercomputing Seed Fund proposal: mapping milk peptides to gut receptors.

**Live page:** https://kuhfeldrf.github.io/huang-seedfunding-proposal/

Eight scenes follow the seed fund narrative: digestion releases thousands of milk peptides whose functions are largely unexplored; why a receptor-centric screen beats one-peptide-at-a-time discovery; the ~3 million peptide–receptor pairs; Aim 1 (co-folding + pharmacophore motif matching across 204 receptors); validation at the μ-opioid receptor (8F7Q, Protenix + MSA); Aim 2 (activation MD: β-casomorphin as agonist vs casoxin as antagonist, with a 7-helix GPCR that opens TM6 to couple a G protein); the 144-GPU hero run; and the resulting peptide–receptor network projected into receptor groups, including orphan receptors.

Narration is pre-recorded with the open-source Kokoro-82M neural text-to-speech model (British male voice `bm_george`, Apache-2.0) and stored as MP3s in `audio/`, so it sounds the same in every browser and needs no server. Captions follow along on screen.
